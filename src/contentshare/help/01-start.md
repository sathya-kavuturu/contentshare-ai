# Getting started

ContentShare reads the content requests that departments email you, finds the program on your
storage server, copies it to that department's folder **and checks every file against the
original**, then replies in the same email conversation.

**Nothing is copied and nothing is sent until you click.** The daily check only reads mail and
adds cards to the Requests screen.

## The five steps

1. **Add your storage folders.** *Settings → General → Storage folders to search.* These are the
   folders on the server that hold the programs. ContentShare only reads them; it never changes
   or deletes anything there.
2. **Add your departments.** *Settings → Departments → Add…* Each department has the email
   addresses that may ask, and one folder its copies go to.
3. **Connect Gmail** (once). See [Connect Gmail](help:gmail).
4. **Refresh the index.** *Settings → Index → Refresh index now.* This reads the folder and file
   names on the server so requests can be matched quickly. It is repeated about once a day.
5. **Press Check now** on the Requests screen. Each request line becomes a card.

Start with **dry-run mode** switched on (it is on after the first-run setup). Approving a card
then only reports what *would* be copied and no email is sent. Switch it off in *Settings →
General* once the results look right.

## The screens

| Screen | What it is for |
|---|---|
| **Requests** | New requests as cards. Check them, then approve. See [Using the app](help:use). |
| **Active copies** | Progress, speed and time left. Pause, resume or cancel. |
| **History** | Every request with a step-by-step record. Export it to a spreadsheet. |
| **Settings** | Everything you can change. See [Settings explained](help:settings). |
| **Help** | This guide. |

## Safe by design

* Only emails from the senders you list are read.
* Mail that Gmail cannot confirm came from the real sender needs one extra tick from you.
* Every copied file is read back from the destination and compared with the original. A file
  that does not match is copied again, and a request is never reported as shared unless every
  file matched.
* Pop-ups show counts only ("3 new requests"), never names, subjects or folders.
